# px4-ros2-autonomous-drone-navigation
PX4 and ROS 2 based autonomous drone navigation simulation using Gazebo and LiDAR.

### 👤 Personal Portfolio & Project Analysis
* **Developer:** Vaisakh TV
* **USN:** ENG24RA1004
* **Objective:** Practical study of ROS 2 frameworks, visual-inertial drone localization, and advanced robotic path planning to build core engineering competencies.

### 🛠️ Core Technology Stack
* **Framework:** ROS 2 (Robot Operating System) for node communications.
* **Autopilot:** PX4 Autopilot for stable flight control and dynamics simulation.
* **Simulator:** Gazebo for 3D physics rendering and multi-sensor integration.
* **Navigation Control:** MPPI (Model Predictive Path Integral) control for real-time trajectory optimization.
* **Hardware Requirements for Simulation Runtime:** Ubuntu Linux system equipped with dedicated NVIDIA GPU runtime architectures.
